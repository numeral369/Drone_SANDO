# Demo video

**`SANDO_demo_medium_mission.mp4`** is the investor video (1920x1080, 38.6 s). It has three parts:
- a title card;
- the flight, shown as a top-down follow view plus a whole-course overview;
- an end card with metrics verified from the recording (see `reports/missions/mission_009_medium_video.md`).

The intermediate data (recordings, render inputs, the rejected first attempt) was deleted. To regenerate the video, see `RECREATE.md`.
